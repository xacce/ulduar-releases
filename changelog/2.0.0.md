## breaking
- [sdk] `ulduar-sdk` 2.0.0 talks to storage v2 only; v1 keys and v1 objects unreachable from SDK 2; migrate: create a v2 user, project, grant and token, copy objects with `ulduar migrate <project>`
- [sdk] `Remote::new(url, key)` -> `Remote::new(url, token)` with a v2 `uld2_...` token; migrate: `ulduar token add <user>`
- [sdk] `StoreOptions.project` required for remote stores; migrate: set `options.project = Some("<project>".into())`
- [sdk] `write_bytes`, `write_shared`, `write_from`, `write_with`, `import_file` take a `Meta` argument; migrate: pass `Meta::default()`, `Meta::typed(t)` or `.named(n)`
- [sdk] cache schema 2 -> 3; SDK 0.1.x caches refused untouched; migrate: point `StoreOptions::root` at a new directory
- [native] native ABI 2 -> 3; SDK 0.1.x crates cannot load SDK 2 native libraries
## added
- [server] storage v2 under `root_dir/v2/` (`chunks/`, `meta.db`, `names.db`), API under `/v2`, next to unchanged v1
- [auth] v2 users with many permanent tokens (`uld2_...`, stored as hashes), per-user `create_project` flag
- [auth] per-project `read`, `write`, `delete` rights; `delete` never granted by default; project creator gets `read`+`write`
- [api] `GET /v2/me`, `GET|POST /v2/projects`
- [api] `POST /v2/projects/{p}/chunks/missing`, `PUT|GET /v2/projects/{p}/chunks/{h}`
- [api] `PUT|GET|DELETE /v2/projects/{p}/objects/{h}`, `GET .../objects/{h}/manifest`, `POST .../objects/missing`
- [api] `GET /v2/projects/{p}/objects?type=&after=&limit=`: listing by nonzero type, paged, ordered by hash
- [api] `GET /v2/projects/{p}/names?name=`, `GET .../names/{h}`
- [store] FastCDC chunks 64 KiB / 256 KiB / 1 MiB, deduplicated across all projects for storage and transfer
- [store] u32 asset `type` per project entry, not part of the hash
- [store] optional object name in `names.db`: upload with name replaces, without name keeps; no history, no name deletion
- [store] chunks unused by any object collected every 600 s after `upload_sweep_days`
- [console] `user add|list|rm|create-projects`, `token add|list|rm`, `project add|list`, `grant`, `revoke`, `grants`
- [console] `migrate <project> [--type T] [ids...]` copies v1 objects into a v2 project
- [console] `verify` re-hashes v2 chunks, reports damaged and missing
- [sdk] `Meta`, `AssetType` (`AssetType::fourcc(b"MESH")`), `Me`, `Project`, `Page`
- [sdk] `Store::me`, `projects`, `create_project`, `list`, `named`, `name`, `delete`
- [sdk] `ErrorKind::Conflict`
- [sdk] `synchronize` uploads only chunks the server lacks; known objects linked without payload
## changed
