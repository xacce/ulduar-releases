## added
- [desktop] `ulduar-desktop`: portable GUI client for storage v2, one executable, no installer; `ulduar-desktop-v2.1.0-windows-x86_64.exe`, `ulduar-desktop-v2.1.0-linux-x86_64.tar.gz` (glibc 2.28, X11 or Wayland, OpenGL)
- [desktop] no macOS asset: linking needs the Apple SDK
- [desktop] accounts on several servers; address + `uld2_...` token; self-signed certificate pinned after fingerprint confirmation; `http://` with a warning
- [desktop] project creation, rights badges per project
- [desktop] upload by OS drag-and-drop or dialog; folder names keep relative paths; content stored under another name keeps that name
- [desktop] download with hash verification and resume; server names sanitized, cannot leave the target folder; collision -> ` (2)` suffix
- [desktop] file details: BLAKE3 hash, size, chunk count, types, date; rename and delete by rights
- [desktop] name and hash-prefix search, keyset paging, virtualized list
- [desktop] dark themes Graphite, Midnight, Ember; languages en, ru
- [desktop] optional master password encrypts `vault.json` (Argon2id, XChaCha20-Poly1305); no password -> tokens in plain text
- [desktop] optional PIN, 4-12 digits: UI lock of the running app, not encryption; `Ctrl+L`, auto-lock after idle minutes
- [desktop] env `ULDUAR_DESKTOP_DIR`: data directory override
- [install] server installation on Ubuntu 24 x86_64 over SSH: password, key file, key text, or SSH agent and default keys; other systems refused in preflight
- [install] host key confirmation; signed `SHA256SUMS` checked on the client, archive SHA256 on the server; systemd service, user `ulduar`, self-signed certificate, Ulduar user, project, token; `ufw` port when active
- [install] SSH credentials never stored; only the resulting account is kept
- [api] `GET /v2/projects/{p}/files?q=&after=&limit=`: named and unnamed objects, paged; `q` matches name substrings and hash prefixes
- [api] `GET /v2/projects/{p}/stats`: distinct objects and bytes
- [client] `Client::with_pinned_certificate`, `v2_files`, `v2_stats`, `v2_manifest`, `v2_set_name`
## changed
- [sdk] `ulduar-sdk` 2.0.0 -> 2.1.0; ABI and API unchanged
